# SyWeDaG Hourly Precipitation Validation

## Introduction

This tool evaluates whether hourly precipitation generated by **SyWeDaG** reproduces relevant statistical and temporal properties of an independent historical/reference dataset.

The comparison is **statistical, not hour-by-hour**. The two CSV files therefore do **not** need to cover the same dates or years. This is appropriate when SyWeDaG generates future synthetic scenarios while the reference dataset contains historical data.

The analysis covers wet-hour frequency, wet/dry spells, intensity distributions, extremes, lag-1 autocorrelation, precipitation events, within-day concentration, monthly behaviour, yearly variability and five-year variability.

## Usage

Install dependencies:

```bash
pip install pandas numpy scipy matplotlib
```

Run:

```bash
python validate_precipitation.py \
    --synthetic sywedag.csv \
    --reference historical.csv \
    --output validation_results
```

The default wet-hour threshold is `0.1 mm/h`. Change it with `--threshold`, e.g.:

```bash
python validate_precipitation.py --synthetic sywedag.csv --reference historical.csv --threshold 1.0
```

## Input format

### SyWeDaG CSV

Only `datetime` and `precipitation` are required; other meteorological columns are ignored.

```text
datetime,temperature,precipitation,wind_speed,wind_direction,humidity,pressure
2028-01-01T00:00:00Z,5.6,0.0,4.5,E,92,1008.6
2028-01-01T01:00:00Z,5.2,0.0,4.6,E,93,1008.6
2028-01-01T02:00:00Z,4.2,0.0,4.7,E,94,1008.6
```

`datetime` is the hourly timestamp and `precipitation` is hourly precipitation in mm.

### Historical/reference CSV

Metadata before the data table is supported, as in an Open-Meteo export:

```text
latitude,longitude,elevation,utc_offset_seconds,timezone,timezone_abbreviation
41.65202,-0.9104309,208.0,0,GMT,GMT

time,precipitation (mm)
2020-01-01T00:00,0.00
2020-01-01T01:00,0.00
2020-01-01T02:00,0.00
```

The script locates the row beginning with `time` and ignores preceding metadata. The precipitation column must contain `precipitation` in its name.

## Important: different periods are allowed

For example:

```text
Historical reference: 2000–2020
SyWeDaG synthetic:    2025–2050
```

The script does not compare matching timestamps. It independently calculates properties for each dataset and compares those properties.

## Metrics

### 1. Wet-hour frequency

Percentage of hours with precipitation greater than or equal to the threshold. Similar values indicate similar precipitation occurrence frequency.

### 2. Wet and dry spells

Consecutive wet or dry hours. Mean, median and maximum duration are reported. These metrics describe persistence and intermittency.

### 3. Intensity and extremes

For wet hours only, the script reports mean, median/P50, P90, P95, P99 and maximum hourly precipitation. Higher quantiles describe the upper tail; the maximum describes the most extreme value in the sample.

### 4. Temporal structure

Lag-1 autocorrelation measures dependence between precipitation at consecutive hours. Higher positive values indicate stronger short-term persistence.

### 5. Precipitation events

An event is defined as one consecutive wet spell. The script reports event count and mean, median and maximum event duration.

### 6. Kolmogorov-Smirnov test

`scipy.stats.ks_2samp` compares the empirical distributions of wet-hour intensities. A smaller KS statistic indicates smaller empirical distribution differences. The p-value tests the null hypothesis that both samples come from the same distribution. It should be interpreted together with descriptive statistics and plots, especially for large samples.

### 7. Intraday concentration

For each UTC hour (00–23), the script calculates the percentage of total precipitation occurring in that hour. Similar profiles indicate similar within-day precipitation timing.

### 8. Daily precipitation

Hourly precipitation is aggregated into UTC daily totals, and mean and median daily precipitation are reported as a daily-scale consistency check.

### 9. Monthly analysis

Main metrics are calculated independently for January through December. This can reveal seasonal differences hidden by global statistics.

### 10. Yearly analysis

Metrics are calculated independently for each year. Years are not paired between datasets; the purpose is to inspect variability within each dataset.

### 11. Five-year analysis

Each dataset is divided into consecutive five-year blocks. Blocks are not assumed to correspond between datasets; they describe multi-year variability within each dataset.

## Percentage differences

The global comparison uses:

`(synthetic - historical) / abs(historical) * 100`

Positive values mean the synthetic metric is higher; negative values mean it is lower. If the reference is zero, the percentage difference is undefined unless both values are zero.

```text
validation_results/
├── comparison_global.csv
├── ks_test.csv
├── monthly_reference.csv
├── monthly_synthetic.csv
├── yearly_reference.csv
├── yearly_synthetic.csv
├── five_year_reference.csv
├── five_year_synthetic.csv
├── hourly_profile.csv
├── intensity_quantile_curve.png
├── spell_duration_histograms.png
├── intraday_concentration.png
└── autocorrelation.png
```

The terminal prints a structured English report containing **all global metrics**, their historical and synthetic values, percentage differences, the KS test, and the complete 24-hour intraday concentration table.

## Visualisations

- **`intensity_quantile_curve.png`**: empirical wet-hour intensity curves on logarithmic axes; useful for typical and upper-tail behaviour.
- **`spell_duration_histograms.png`**: wet- and dry-spell duration distributions; useful for persistence/intermittency.
- **`intraday_concentration.png`**: precipitation concentration across the 24 UTC hours; useful for within-day temporal structure.
- **`autocorrelation.png`**: autocorrelation for lags 1–24 hours; useful for short-term temporal dependence.

## Recommended interpretation

The tool is not intended to produce a binary “valid/invalid” decision. Results should be considered jointly across:

1. occurrence — wet-hour frequency;
2. persistence — wet/dry spells and autocorrelation;
3. intensity — P50, P90, P95 and P99;
4. extremes — upper tail and maximum hourly precipitation;
5. temporal structure — intraday concentration and autocorrelation;
6. seasonality — monthly statistics;
7. variability — yearly and five-year statistics;
8. distributional similarity — KS statistic and intensity curves.

No single metric is sufficient on its own.

## Limitations

- Validation quality depends on the reference dataset and its representativeness.
- If Open-Meteo is used, it should be described as the reference data source, not as direct observations from a physical weather station.
- A single-location case study cannot establish global validity.
- Different historical and synthetic periods assess statistical compatibility rather than exact temporal reproduction.
- Events are currently defined simply as consecutive wet hours; no minimum inter-event dry period is imposed.
- The KS test only evaluates wet-hour intensity distributions and therefore does not validate every aspect of hourly precipitation behaviour.

## Scientific purpose

The objective is not to prove that synthetic precipitation exactly reproduces historical precipitation. The objective is to evaluate whether the generated hourly series reproduces relevant statistical properties of an independent hourly reference dataset.

This is particularly relevant to temporal downscaling: preserving daily precipitation totals alone does not guarantee realistic hourly occurrence, persistence, intensity, extremes or within-day temporal structure.
